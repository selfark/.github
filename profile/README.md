# SelfArk

We develop software products and tools.

## Products

- **[LocArk](https://locark.com)** — A local-first workspace for notes, passwords, kanban boards, and mind maps.
- **[XShots](https://selfark.com/xshots)** — A native macOS app for designing, localizing, previewing, and exporting App Store screenshot sets.
- **[SpriteArk](https://spriteark.com)** — A native macOS workspace for generating and editing game art, with optional AI providers and local MCP automation.
- **[TypeNod](https://typenod.com)** — An on-device translation input method for Mac. Preview translations as you type and insert them into compatible text fields without switching windows or copying and pasting.
